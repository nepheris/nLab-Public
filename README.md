# nLab public

Ce dépôt constitue l’espace public du projet **nLab**.

> **Statut : projet en cours de développement.**

nLab est actuellement en phase de conception, de structuration et de refonte globale. Le contenu de ce dépôt est donc appelé à évoluer au fur et à mesure de la stabilisation du système.

## Principe de publication

Ce dépôt est destiné uniquement aux artefacts nLab explicitement rendus publics et publiés en version de production.

Les travaux en développement, données privées, configurations personnelles, secrets, fichiers temporaires et éléments de bac à sable restent dans les espaces privés du projet nLab.

## Structure actuelle

- `APP-Applications/` — applications nLab publiques.
- `BRK-Briques/` — briques réutilisables publiques.
- `FRMW-Frameworks/` — frameworks nLab publics.
- `Library/` — bibliothèque publique mutualisée.
- `Info/` — informations générales complémentaires sur le projet public.

Les autres familles et ressources seront ajoutées uniquement lorsque leur structure aura été définie et validée.
