# Bac à sable — NLabpublic

Cet espace est réservé aux essais, prototypes, tests temporaires et expérimentations liés au dépôt `NLabpublic`.

Le contenu de ce dossier n'est pas considéré comme stable ni comme faisant partie de la production tant qu'il n'a pas été validé et déplacé vers son emplacement définitif.

Le fichier `README.md` permet également de conserver ce dossier dans Git même lorsqu'aucun autre fichier de test n'est présent.
